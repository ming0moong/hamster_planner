Hamster Planner Weekday Routine
===============================

이번 버전 변경점
- 루틴을 매일이 아니라 요일별로도 설정 가능
- 루틴 추가할 때 일~토 원하는 요일만 선택 가능
- 매일 버튼으로 전체 요일 한 번에 선택 가능
- 저장된 루틴 목록에 반복 요일 표시
- 선택한 날짜의 요일과 맞는 루틴만 자동으로 들어감
- 기존 기능 유지: 달력 토글 / 루틴 접기 / 진행률 바 / 빠른 추가 / 이미지 저장 / PWA

파일 구성
- index.html
- manifest.json
- service-worker.js
- icons/

사용법
1. VS Code + Live Server 또는 npx serve 로 실행
2. Safari에서 열면 홈 화면에 추가 가능
3. 고정 루틴 관리 열기
4. 루틴 이름 입력
5. 반복 요일에서 원하는 요일 선택
6. 추가 버튼 누르면 해당 요일에만 자동으로 들어감
7. 매일로 쓰고 싶으면 매일 버튼 누른 뒤 추가

주의
- file:// 로 직접 열면 서비스워커가 안 붙을 수 있음
- 기존 캐시가 남아 있으면 새로고침 또는 캐시 삭제
