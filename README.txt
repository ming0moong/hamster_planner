Hamster Planner - Clean Reorganized Version

포함 기능
- 오늘 / 날짜 / 루틴 / 성장 화면 분리
- 레벨 카드 크게 강조
- 날짜별 투두 저장
- 요일별 루틴 자동 추가
- 내일로 복사 / 완료만 지우기 / 스토리 저장
- PWA 설치 / 서비스워커

실행 방법
1. 폴더째로 압축 해제
2. GitHub Pages 또는 Netlify에 업로드
3. 또는 VS Code + Live Server로 실행
4. 아이폰은 Safari에서 열고 공유 버튼 -> 홈 화면에 추가

폴더 구조
- index.html
- manifest.json
- service-worker.js
- icons/

주의
- file:// 로 직접 열면 PWA 설치가 제대로 안 될 수 있음
- 기존 버전이 캐시에 남아 보이면 새로고침 또는 캐시 삭제
